## ◈ Project Overview

MCA GITAM Academic Resource Hub brings subject-wise study notes, learning materials, and previous-year question papers together in one accessible platform.

The application is designed to improve resource discovery and support a more organized academic preparation experience.

## ✦ Key Features

- **Subject-Wise Library** — Browse available academic resources.
- **Notes & Study Materials** — Access available revision materials.
- **Previous-Year Questions** — Find examination practice resources.
- **Search** — Locate resources using keywords.
- **PDF Viewer** — Open supported study documents.
- **Dark Mode** — Switch between visual themes.
- **Doubt Buddy** — Explore predefined study-related answers.
